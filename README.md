# Learning Sandbox

A collection of mini-projects, language experiments, and conceptual prototypes.

## Projects

| Directory | Topic / Tech | Description |
| :--- | :--- | :--- |
| [`01-async-flow`](01-async-flow) | Asyncio, WebSockets, FastAPI | In-memory backend demonstrating real-time command streaming, producer-consumer worker pools, cancellation, and heartbeat lifecycle management. |
| [`02-langchain-ecosystem`](02-langchain-ecosystem) | LangChain, LangGraph, LangSmith | Intensive exploration of LCEL, vector databases, stateful agent graphs, and observability. |
| [`03-student-performance-bayes`](03-student-performance-bayes) | Bayesian Networks, Exact/Approx Inference, pgmpy | Educational student performance prediction implementing exact & approximate inference algorithms from scratch and learning parameters from data. |

## Repository Structure

Each subfolder is an independent module with its own dependencies and configurations.
